``
Hibernate: create table tb_user_session (user_session_id bigint not null auto_increment, create_at datetime, delete_yn varchar(255), update_at datetime, user_session_expired_at datetime, user_session_ip varchar(255), user_session_key varchar(255), user_id bigint, primary key (user_session_id)) type=MyISAM
```

위와 같은 식으로 에러가 발생한다면,

``` yaml
jpa:
  show-sql: true
  database-platform: org.hibernate.dialect.MySQL57Dialect
```

org.hibernate.dialect.MySQLDialect 을
org.hibernate.dialect.MySQL57Dialect 으로 변경해보자.


### 그래도 안된다면

```
database-platform: org.hibernate.dialect.MySQL57Dialect
```

위에 yaml 에 위 문구를 빼보자.
