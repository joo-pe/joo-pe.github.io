1. 왜 사용하나? Java Generic .

- java 1.5 부터 사용해왔고, 주로 java collection 에 사용된다.
- Java Generic 이 있기 전에는 collection 을 사용할 때 정확한 타입이 명시가 되어 있지 않아, 혼란스러운 경우가 있었다.
- 클래스에서 사용할 타입을 클래스 외부에서 설정하는 타입이다. 

2. Java Generic의 유형 
- Interface Generic
- Method Generic
- WildCard Generic
  
3. 타입의 매개변수 유형
   E-Element
   K-Key 
   N-Number
   T-Type
   V-Value
